# Alba

Persönliches Betriebssystem für den Tag. To-dos datieren, auf Heute abhaken, Ziele als Sätze, Ideen als Dokumente, speichern im Log, Routinen halten.

**App:** [https://llbgroup.github.io/alba/](https://llbgroup.github.io/alba/)

Daten bleiben im Browser (`localStorage`). Kein Konto, keine Wolke. Beim ersten leeren Start ein paar Attrappen, die die Flächen erklären.

## Nutzen und weitergeben

1. Die Adresse öffnen.
2. Chrome/Edge: Chip **unten rechts** → Als App. Safari: Ablage → Zum Dock.
3. Jede Person hat eigene Daten in ihrem Browser. Der Link teilt das Werkzeug, nicht das Leben.

Ein Push auf `main` baut die Seite neu. Wer die App (oder den Tab) wieder öffnet, bekommt den neuen Stand — ohne neu zu installieren.

## Lokal entwickeln

**Port 4765 nicht ändern.** `http://127.0.0.1:4765` ist ein anderes Konto als die gehostete Adresse.

```bash
npm install
npm run dev
```
